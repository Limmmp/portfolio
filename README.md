# Портфолио — Денис

Одностраничник на Vite + Three.js + GSAP. Сайт меняет облик по мере скролла:
каждый кейс перекрашивает страницу в свою палитру, поэтому портфолио само
показывает диапазон, а не рассказывает о нём.

## Запуск

```
npm install
npm run dev      # http://localhost:4180
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

## Как это устроено

**Четыре акта.** Палитры описаны один раз в [src/js/themes.js](src/js/themes.js) —
оттуда их читают и CSS, и WebGL, иначе фон сцены разъехался бы с фоном страницы.

| Акт | Где | Настроение |
|-----|-----|-----------|
| `void` | герой, услуги, процесс, обо мне | чёрный, туман, лайм |
| `cream` | кейс СТРЕЛА, финальный экран | кремовый свет, стекло, засечки |
| `mono` | кейс NIX | чёрно-белое кино, сканлайны |
| `neon` | кейс КОМПРОМАТ | маджента, неоновая сетка |

Смену акта запускает `data-theme-section` на секции. Переход плавный за счёт
`@property`-регистрации переменных: браузер интерполирует сам цвет, а не
переключает его рывком.

**Сцена.** Один `<canvas>` на всю страницу: шейдерный фон с четырьмя режимами
([src/gl/shaders/bg.frag](src/gl/shaders/bg.frag)) и 3D-макет сайта
([src/gl/site-model.js](src/gl/site-model.js)) — экран, шапка, первый блок,
карточки и кнопка. По скроллу детали слетаются из хаоса в собранный интерфейс,
а к трети страницы макет уходит со сцены: мысль донесена, дальше он только
мешал бы карточкам. Макет и фон лежат в одной сцене — иначе `transmission`
не захватил бы фон и стекло не преломляло бы его по-настоящему.

**Производительность.** Three.js грузится отдельным чанком уже после первой
отрисовки. Сцена следит за частотой кадров и на слабом железе снимает сначала
макет, потом разрешение — но только при устойчивой просадке (скользящее
среднее за два окна по ~2 с, после 4 с разгона). Считать отдельные медленные
кадры нельзя: компиляция шейдеров даёт всплеск, и макет исчезал навсегда
на машинах, которые его прекрасно тянут. На телефонах макета нет изначально —
`transmission` рендерит сцену дважды, это слишком дорого.

**Отладка.** `?glass=off` — выключить стекло. В dev-режиме доступен
`__pf.applyTheme('neon')`, чтобы посмотреть акт без скролла.

## Доступность

При `prefers-reduced-motion: reduce` отключаются WebGL, плавный скролл и все
анимации — сайт остаётся целым и читаемым, просто статичным.

## Деплой

```
npx vercel --prod
```

Настройки сборки закреплены в [vercel.json](vercel.json), чтобы деплой не
зависел от того, что записано в дашборде (проект изначально заводился как
статика без сборки).

## Что поменять перед запуском

1. **Портрет — опционально, секция работает без него.** Заглушка убрана,
   «Обо мне» держится на тексте, таблице фактов и блоке гарантий. Если
   появится нормальный кадр (вертикальный, от 900×1200, лицо открыто, фон
   не спорит) — вернуть колонку с фото несложно: сетка `.about__grid`
   рассчитана на два столбца, стили портрета лежат в истории правок.
   Что снимать: у окна в пасмурный день, камера на уровне глаз, руки от лица,
   однотонный фон, кадр по грудь. Десять минут и штатив из стопки книг.
2. **Цены.** Сайты 20/40/60 тыс. — как было. Добавлены боты (от 15 тыс.)
   и мобильные приложения (от 90 тыс.) — эти цифры я поставил по аналогии,
   проверь их под себя. Отдельно стоит вернуться к вопросу планки: базовые
   сайты сейчас делает ИИ за вечер, и 20 тыс. — это ровно тот сегмент, где
   конкурируешь с конструкторами. Твоё преимущество в том, чего ИИ не
   закрывает: живая админка, бэкенд, 3D, интеграции.
3. **Ссылки на живые кейсы** — карточки пока некликабельны. Когда СТРЕЛА,
   NIX и КОМПРОМАТ переедут на постоянные домены, обернуть `.case__lead`
   в ссылки.
4. **Отзывы и цифры.** Их нет и я их не выдумывал. Как появятся реальные —
   это самое сильное, что можно добавить на такой сайт.
5. **Домен** — бесплатные `.page.gd` выглядят несерьёзно для клиентов.

## Как пересобрать кадры кейсов

В `public/assets/cases/` лежат 12 скриншотов, снятые с локальных сборок
`Strela`, `nix-portfolio` и `Kompromat` через Playwright с системным Chrome
(CDN Playwright заблокирован, поэтому браузер берётся по `executablePath`).
Если обновишь сайты кейсов — подними их `vite preview` и пересними, затем
сожми в webp: PNG с ретины весили 17 МБ, после конвертации — 0.36 МБ.
